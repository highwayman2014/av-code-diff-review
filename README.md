# av-code-diff-review

Навык создает HTML-отчет по изменениям кода 1С (BSL) в Git.
Отчет помогает понять, что изменилось и как это влияет на поведение кода.
Он не заменяет ревью дефектов и тесты в 1С.

## Как работает

1. Ты указываешь репозиторий и изменения для разбора.
2. Агент читает код до и после изменения.
3. Агент добавляет пояснения. Для сложной логики он использует схемы или псевдокод.
4. Скрипт собирает HTML и проверяет оформление.

Исходники и ветки Git не изменяются.
Код в 1С не выполняется.

## Что получаем

HTML-файл с оглавлением по методам, кодом до и после изменения и пояснениями.
Отчет можно открыть в браузере без сети или передать коллеге.
Для больших изменений агент создает несколько страниц.

Отчет содержит исходный код, в том числе в свернутых блоках.
Перед передачей проверь, что его можно раскрывать получателю.

## Требования

- Python 3.10 или новее, доступный командой `python`.
- Git в `PATH`.
- Локальный Git-репозиторий с BSL-модулями в UTF-8.
- Коммиты с состояниями до и после изменения, доступные локально.

Незакоммиченные изменения в отчет не входят.
Платформа 1С, MCP-серверы и сторонние пакеты Python не нужны.

## Установка

### Через skills CLI

Нужен Node.js 22.20 или новее с командой `npx`.
Для загрузки навыка нужен доступ к сети.

Из каталога проекта выполни:

```bash
npx skills add highwayman2014/av-code-diff-review --skill av-code-diff-review
```

Выбери агента в диалоге установщика.
Для установки на уровне пользователя добавь `-g`:

```bash
npx skills add highwayman2014/av-code-diff-review --skill av-code-diff-review -g
```

### Через Git

Склонируй репозиторий в каталог навыков своего агента:

```bash
git clone https://github.com/highwayman2014/av-code-diff-review.git <skills-dir>/av-code-diff-review
```

Замени `<skills-dir>` на каталог навыков приложения.
Если приложение загружает навыки при запуске, перезапусти его.

## Как использовать

Пример запроса агенту:

```text
Используй av-code-diff-review.
Разбери изменения в репозитории /work/service между коммитами <base> и <head>.
Объясни, что изменилось в поведении кода.
Сохрани HTML-отчет в /work/review.
```

Замени путь и коммиты на свои значения.
Если есть постановка задачи, передай ее агенту для объяснения цели изменений.

Без явного диапазона навык сравнивает `git merge-base main HEAD` и `HEAD`.
Для этого нужны локальная ветка `main` и история до общего предка.

Поддерживаются изменения внутри процедур и функций BSL.
XML и другие языки не поддерживаются.

Инструкции для агента находятся в [SKILL.md](SKILL.md).
